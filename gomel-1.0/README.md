# Gomel Programming Language

Gomel — это экспериментальный объектно-ориентированный язык программирования, 
транслируемый в C. Он поддерживает классы, наследование и полиморфизм (vtable).

## Особенности
- Собственный синтаксис (`form`, `number`, `loop`, `provided`, `plus`)
- Транспиляция в чистый и быстрый C-код
- Поддержка ООП: наследование (`inherit`) и виртуальные методы
- Управление памятью через `plus` (malloc)

## Установка и запуск
1. Установите GCC (MinGW) и добавьте его в PATH.
2. Скачайте `gomel.exe` и `gomelc.exe`.
3. Напишите программу в файле `hello.gom`:
   ```gomel
   number main() {
       printf("Hello, World from Gomel!\n");
       return 0;
   }
